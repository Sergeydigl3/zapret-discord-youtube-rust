# 💻 Zapret-Rust TUI

Plug&Play-решение для обхода DPI-блокировок.

---

## 🧠 Как это работает — простыми словами

**Провайдер проверяет трафик.** У него есть фильтр — DPI. Это программа, которая смотрит, куда и как вы подключаетесь, и не пускает на некоторые сайты.

**Zapret обходит фильтр.** Он отправляет пакеты так, что фильтр не понимает, что это за соединение, а сайт понимает и отвечает. Это и есть «обход DPI».

**Стратегия — это рецепт.** В ней записано, как именно менять пакеты. У разных провайдеров разные фильтры, поэтому рецепты тоже разные. Не подошёл один — пробуем другой.

**Фейк-пакет — это обманка.** Программа отправляет лишний пакет-двойник. Фильтр отвлекается на него, а настоящее соединение проходит.

**Геймфильтр — это не только игры.** Он добавляет в обход широкий диапазон портов для TCP, UDP или обоих протоколов. Поэтому он помогает не только играм, но и другим программам.

**TTL — это запас «шагов» у пакета.** На каждом шаге через роутер запас уменьшается. Когда запас кончился, пакет исчезает. Иногда фильтр не видит пакеты, которые исчезают по пути, поэтому TTL помогает обойти блокировку. Его можно подобрать вручную или автоматически.

**Автотюн — это перебор.** Программа по очереди включает стратегии и проверяет, открываются ли выбранные сайты (по умолчанию — Discord). В конце она показывает, какая стратегия сработала лучше.

**Режим роутера** делает компьютер «передатчиком» интернета для телефона. Трафик телефона идёт через компьютер и тоже обходит фильтр. Если выбранный фаервол умеет, программа сама включает NAT; если нет — NAT нужно настроить отдельно.

## 🔧 Требования к системе

Программе нужны права администратора: она меняет сетевые правила и ставит фоновую службу. Точный набор доступных бэкендов, интерфейсов и флагов зависит от системы и сборки — его всегда показывает `zapret-rust --help` на вашем компьютере.

| Система | Что дополнительно нужно |
| :--- | :--- |
| **Linux** | Фаервол, с которым умеет работать программа (список показывает `--help`), и права `root` |
| **Windows** | Права Администратора; драйвер перехвата пакетов скачивается автоматически |

Поддержка других систем зависит от сборки: если программа собрана под вашу систему, `--help` покажет её возможности.

## Быстрый старт

### 1. Сборка из исходников

Для сборки нужен Rust и команда `cargo`.

```bash
git clone https://github.com/Sergeydigl3/zapret-discord-youtube-rust.git
cd zapret-discord-youtube-rust

cargo build --release
```

Готовый файл появится по пути `target/release/zapret-rust`.

---

### 1.1 Готовый файл

Если собирать проект не хочется, готовые стабильные версии лежат во вкладке Releases. Скачайте файл, положите его в любую папку и запустите.

---

### 1.2 Установка через Nix (Flakes)

Если у вас есть Nix с поддержкой Flakes, можно запустить или установить утилиту прямо из репозитория. Пакет собирается из исходников, а готового кэша у проекта нет, поэтому первый запуск будет с компиляцией:

```bash
nix run github:Sergeydigl3/zapret-discord-youtube-rust
```

#### Использование в качестве пакета

Добавление в конфигурацию NixOS (пример):

```nix
{
  inputs.zapret-rust.url = "github:Sergeydigl3/zapret-discord-youtube-rust";

  outputs = { self, nixpkgs, zapret-rust, ... }: {
    nixosConfigurations.my-host = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        ./configuration.nix
        {
          environment.systemPackages = [
            zapret-rust.packages.x86_64-linux.default
          ];
        }
      ];
    };
  };
}
```

Бинарник оборачивается (`wrapProgram`) так, что при запуске ему доступны `nftables` и `polkit` из PATH.

#### Использование в качестве системной службы (NixOS Module)

В репозитории есть NixOS-модуль. Он помогает настроить `zapret-rust` и запускать его в фоне через `systemd`.

Пример подключения модуля и настройки службы:

```nix
{
  inputs.zapret-rust.url = "github:Sergeydigl3/zapret-discord-youtube-rust";

  outputs = { self, nixpkgs, zapret-rust, ... }: {
    nixosConfigurations.my-host = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        ./configuration.nix
        zapret-rust.nixosModules.zapret-rust
        {
          services.zapret-rust = {
            enable = true;
            interface = "any";
            strategy = "general.bat";
            backend = "nftables";
          };
        }
      ];
    };
  };
}
```

#### Среда разработки

Используйте предоставленный dev-шелл (flake):

```bash
nix develop .
```

Он добавляет в окружение `cargo`, `rustc`, `rustfmt`, `clippy`, `rust-analyzer`, а также `nftables` и `polkit`.

### 2. Запуск в интерактивном режиме (TUI)

Просто запустите утилиту без аргументов. Она сама проверит права и при необходимости попросит пароль:

```bash
./target/release/zapret-rust
```
На Windows просто запустите скачанный файл двойным щелчком.

> [!TIP]
> При первом запуске откройте меню **📥 Загрузчик** (Downloader) → **📦 Скачать всё (по умолчанию)** (Download All). Программа скачает нужные файлы `nfqws`/`winws` и стратегии. После этого выберите интерфейс и стратегию в главном меню и нажмите **🚀 Запустить** (Run).

#### Управление

Навигация по всем меню — стрелками или клавишами `h` `j` `k` `l`, как в Vim:

| Клавиши | Действие |
| --- | --- |
| `↑` / `↓` или `k` / `j` | Перейти к другому пункту меню |
| `←` / `→` или `h` / `l` | Изменить значение пункта |
| `ENTER` / `SPACE` | Переключить значение, открыть подменю или выполнить действие |
| `ESC` / `q` | Вернуться назад; из главного меню — выйти (во время автотюна — отменить) |

## 💻 Использование CLI (неинтерактивный режим)

Утилиту можно запускать из консоли с параметрами — например, в своих скриптах или при автозапуске. TUI остаётся режимом по умолчанию, но **все действия из меню доступны флагами**: настройка, загрузка, автотюн, служба, списки и запуск без TUI.

Флаги запуска (`-c`, `-s`, `-i`, `-t`, `-u`, `--run`, `--no-tui`) сразу запускают программу без меню. Если нужно только изменить настройку, используйте флаги `--set-*`. Некоторые флаги зависят от системы: если возможности нет, такого флага в `--help` не будет.

### Что автотюн проверяет по умолчанию (запуск из консоли)

Если не указывать флаги `--autotune-*`, программа:

* берёт пресет доменов **Discord**;
* делает по **3** запроса на каждый сайт и протокол;
* проверяет **все установленные** стратегии;
* проверяет все протоколы, которые умеет программа;
* выполняет все проверки блокировок, которые есть в программе.

В TUI эти параметры выбираются в меню автотюна. Стратегии там нужно отметить вручную.

### Примеры запуска

*   **Запуск с определённой стратегией на интерфейсе eth0:**
    ```bash
    sudo ./zapret-rust -s discord.bat -i eth0
    ```
*   **Запуск с включёнными геймфильтрами:**
    ```bash
    sudo ./zapret-rust -s general.bat -t -u
    ```
*   **Запуск с готовым файлом настроек:**
    ```bash
    sudo ./zapret-rust --config conf.env
    ```
*   **Настройка без TUI (сохраняет и выходит):**
    ```bash
    sudo ./zapret-rust --set-interface eth0 --set-strategy discord.bat --set-gamefilter-tcp on
    ```
*   **Настройка и запуск без TUI:**
    ```bash
    sudo ./zapret-rust --no-tui -s discord.bat -i eth0 -t
    ```
*   **Загрузка рекомендуемых версий и автотюн без TUI:**
    ```bash
    sudo ./zapret-rust --download-defaults
    sudo ./zapret-rust --autotune --autotune-presets discord,youtube --autotune-strategies all
    ```
*   **Проверка состояния без прав администратора:**
    ```bash
    ./zapret-rust --status
    ./zapret-rust --show-config
    ./zapret-rust --list-strategies
    ```

## 📂 Структура конфигурации и кэша

Скачанные файлы и настройки хранятся в папке кэша. По умолчанию она находится рядом с исполняемым файлом. Другую папку можно задать через аргумент `--cache-dir` или переменную окружения `ZAPRET_CACHE_DIR`:

*   `bin/` — исполняемые файлы `nfqws` или `winws.exe` + библиотеки WinDivert.
*   `zapret-discord-youtube-linux/` — скачанный репозиторий: стратегии, списки и `.bin`-файлы фейков.
*   `custom-strategies/` — ваши собственные стратегии. Они не пропадают при обновлении репозитория.
*   `autotune_preset_discord.txt`, `autotune_preset_youtube.txt`, `autotune_preset_social.txt`, `autotune_custom.txt` — редактируемые списки доменов для пресетов автотюна.
*   `ttl_domains.txt` — редактируемый список доменов для автоподбора TTL.
*   `conf.env` — файл настроек последнего сеанса. Формат файла:
    ```env
    # Эти строки нужны не на каждой системе:
    interface=any
    router=false
    strategy=discord.bat
    gamefiltertcp=true
    gamefilterudp=true
    backend=nftables
    active_discord_fake=quic_initial_steamcommunity_com.bin
    active_gamefilter_fake=quic_initial_4pda_to.bin
    # Нижняя граница DPI TTL (пусто = авто):
    dpi_desync_ttl=
    ```

> [!NOTE]
> Файлы списков (`ipset-all.txt`, `ipset-exclude.txt` и другие) лежат рядом с исполняемым файлом, в папке `zapret-discord-youtube-linux/lists`, а не в папке кэша. Поэтому `--cache-dir` и `ZAPRET_CACHE_DIR` на них не влияют.

## 🔧 Управление фоновой службой (автозапуск)

Программу можно запускать в фоне как системную службу. Тогда она будет работать сама, без открытого окна, и запустится при включении компьютера.

### Обычная установка через TUI

1. Запустите программу в режиме TUI.
2. Выберите сетевой интерфейс, подходящую стратегию обхода и геймфильтры.
3. Откройте раздел **🔧 Служба (Фон)** (Service Management).
4. Выберите **📦 Установить службу** (Install Service). Программа создаст службу и сразу запустит её.

Этот способ работает там, где программе разрешено записывать файлы служб. Права администратора она запросит сама.

> [!IMPORTANT]
> **В NixOS установить или удалить службу из TUI нельзя.** Системные папки в NixOS доступны только для чтения, поэтому программа не может создать там файл службы. В NixOS служба настраивается только через NixOS-модуль (см. раздел «Установка через Nix» выше).

> [!NOTE]
> *   На **Linux** служба называется `zapret-rust` (на systemd — `zapret-rust.service`) и включается в автозапуск при старте системы.
> *   На **Windows** служба устанавливается как системная служба Windows с флагом запуска `--service`.

### NixOS

Служба описывается в конфигурации NixOS через модуль:

```nix
services.zapret-rust.enable = true;
```

После `nixos-rebuild switch` система сама создаст службу и включит её в автозапуск. Настройки останутся в конфигурации NixOS.

## 🔒 Исключения Windows Defender

Если встроенный антивирус Windows мешает запускать `winws.exe` или драйвер `WinDivert`, добавьте папку программы в исключения прямо из TUI:
1. Запустите TUI (программа сама попросит права администратора).
2. Откройте **🔒 Исключения Defender** (Defender Exclusions).
3. Нажмите **➕ Добавить папку в исключения** (Add folder to exclusions).
4. Программа запустит PowerShell в фоне и добавит папку кэша в белый список антивируса.

## 🔍 Автотюн: проверки блокировок

Автотюн — это автоматическая проверка. Сначала он смотрит, **как именно** провайдер мешает: подменяет DNS, обрывает соединение, прячет имя сайта и так далее. Потом он **включает стратегии по очереди** и проверяет на настоящих сайтах, какая из них работает. В конце видно, какой рецепт обхода лучше всего подходит вашему провайдеру.

### Пункты меню автотюна

| Пункт | Что он делает |
|:---|:---|
| **🌐 Домены** | Какие сайты проверять. Можно выбрать Discord, YouTube, соцсети или свой список. Разрешено выбрать несколько вариантов сразу. По умолчанию выбран только Discord. |
| **🎯 Запросов/домен** | Сколько раз пробовать каждый протокол для каждого сайта. По умолчанию 3. Все попытки должны пройти: если хотя бы одна не удалась, протокол считается заблокированным. |
| **📋 Стратегии** | Какие рецепты обхода проверять. Программа запускает стратегию, ждёт запуска `nfqws`/`winws`, а затем смотрит, открываются ли заблокированные сайты. |
| **🔌 Протоколы** | Что проверять у каждого сайта: HTTP, TLS 1.2, TLS 1.3 или QUIC. |
| **🚫 Блокировки** | Какие способы блокировки искать в сети: DNS-подмену, TCP RST, SNI, SIBERIAN, QUIC или CIDR. |
| **📝 Списки доменов** | Текстовые файлы со списками сайтов для каждого пресета и для подбора TTL. Свои списки полностью заменяют встроенные. Один сайт — одна строка, строки с `#` не читаются. |
| **📊 Результаты** | Что показал последний запуск автотюна. |
| **🚀 Запустить перебор** | Начать проверку. Во время работы идёт таймер `[MM:SS]`, а свой TTL временно становится `auto`. Нажатие `q` или `ESC` останавливает проверку и возвращает прежние настройки сети и TTL. |
| **🔙 Назад** | Вернуться в главное меню. |

> [!IMPORTANT]
> 🚨 **Отключите все обходы блокировок перед запуском автотюна!** Если zapret/nfqws уже запущен, автотюн не начнёт работу и покажет ошибку.

### Протоколы

| Протокол | Что проверяет |
|:---|:---|
| **HTTP (порт 80)** | Отправляет обычный HTTP-запрос. Любой ответ сайта считается успехом. |
| **TLS 1.2** | Сначала проверяет, открывается ли порт 443. Затем при проверке стратегии делает настоящий HTTPS-запрос с TLS 1.2. |
| **TLS 1.3** | Так же проверяет порт 443, а при проверке стратегии делает настоящий HTTPS-запрос с TLS 1.3. Именно так браузеры обычно открывают сайты, поэтому это главная проверка. |
| **QUIC (UDP 443)** | Отправляет настоящий QUIC-пакет версии 1 по UDP-порту 443 и ждёт ответ. Проверяет, проходит ли он через фильтр. |

### Проверки блокировок

| Проверка | Что она значит |
|:---|:---|
| **DNS-спуфинг** | Сравнивает адреса сайта с правильными. Если адреса другие, провайдер подменяет DNS. |
| **TCP RST** | Пробует соединиться и смотрит, обрывает ли провайдер соединение (RST) или заставляет ждать. |
| **SNI** | Сравнивает заход по имени сайта и по его IP-адресу. Если по IP открывается, а по имени нет, провайдер читает имя сайта в TLS. |
| **SIBERIAN** | Открывает 15 и больше соединений к адресам одного сайта. Если часть соединений не открывается, провайдер ограничивает их количество. |
| **QUIC** | Отправляет настоящий QUIC-пакет и ждёт ответ. Если ответа нет, QUIC заблокирован. Это надёжнее простых «пустышек», которые проходят не через все фильтры. |
| **CIDR** | Пробует адреса из разных подсетей (Cloudflare, Google DNS, Yandex DNS, Discord CDN). Если часть не работает, блокировка идёт по диапазонам IP. |

### Как читать результаты

**Сетевые проверки:**
- ✅ — способ блокировки не найден.
- ❌ — способ блокировки найден. Выбирайте стратегию, которая умеет его обходить.
- ⏩ — проверку не удалось выполнить: нет интернета или результат непонятный.

**Проверки протоколов сайтов (до включения стратегии):**
- ✅ — протокол работает и без обхода.
- ❌ — протокол заблокирован.
- ⏩ — проверка пропущена: сайт недоступен.

**Проверки стратегий:**
- ✅ — стратегия помогает, сайты открываются.
- ❌ — стратегия не помогает, сайты закрыты.
- Стратегия считается рабочей, если через неё по TLS (HTTPS) открывается **не меньше половины** заблокированных сайтов.
- Лучшей считается стратегия, которая работает на большем числе выбранных наборов сайтов, а при равенстве — открывает больше сайтов.

## 🎯 Подбор TTL (автоподбор для DPI)

Иногда стратегия не помогает, потому что фильтр слишком строгий. Тогда может выручить TTL.

TTL — это запас «шагов» у пакета. На каждом шаге через роутер запас уменьшается. Когда запас кончился, пакет исчезает. Иногда фильтр не видит пакеты, которые исчезают по пути, поэтому правильный TTL помогает обойти блокировку.

Пункт **⚙️ Расширенные настройки** → **🎯 Подбор TTL** умеет две вещи:

- **Автоподбор** (`ENTER`): программа по очереди проверяет TTL от 3 до 20. Для каждого значения она запускает `nfqws`/`winws` и смотрит, открываются ли сайты из `ttl_domains.txt` по TLS 1.3. Первое рабочее значение сохраняется в настройки.
- **Своё значение** (`←`/`→`): можно выбрать нижнюю границу TTL от 3 до 20 или вернуть режим `Авто`. Программа начнёт с выбранного числа и при необходимости попробует значения выше (до 20). В режиме `Авто` программа не задаёт TTL — остаются значения из самой стратегии.

Выбранная нижняя граница применяется к каждой группе параметров стратегии при запуске.

> [!NOTE]
> Домены для тестирования можно редактировать в файле `ttl_domains.txt` или через меню **📝 Списки доменов** автотюна.

## 🎭 Смена фейков

> [!IMPORTANT]
> 🚨 **Нужны стратегии с файлами `ACTIVE_DISCORD_UDP.bin` и `ACTIVE_GAME_UDP.bin` — в наборе Flowseal это версия 1.10.0 и новее.**

В меню можно заменить активные .bin-файлы фейков для Discord UDP и геймфильтра UDP. Из консоли это делают флаги `--set-fake-discord` и `--set-fake-gamefilter`.

Фейк — это пакет-обманка. Программа отправляет его вместо настоящего или вместе с ним, чтобы фильтр ошибся и пропустил соединение. Разные фейки ведут себя по-разному, поэтому иногда один файл работает лучше другого.

### Как сменить фейк

1. Откройте **⚙️ Расширенные настройки** → **🎭 Смена фейков**.
2. Выберите, для чего менять фейк: Discord UDP или геймфильтр UDP.
3. Выберите нужный .bin-файл из списка.

Выбранный фейк сразу копируется в `ACTIVE_DISCORD_UDP.bin` или `ACTIVE_GAME_UDP.bin` — эти файлы стратегия использует и при следующих запусках. Имя выбора хранится в `conf.env`, чтобы меню помнило, что выбрано. Если фейк ещё не выбирали, используются файлы по умолчанию: `quic_initial_steamcommunity_com.bin` для Discord и `quic_initial_4pda_to.bin` для геймфильтра UDP.

## 🌐 Режим роутера

**⚙️ Расширенные настройки** → **🌐 Режим роутера** включает режим роутера. Он начнёт работать при следующем запуске: программа разрешит компьютеру пересылать чужой трафик и, если выбранный фаервол умеет, добавит NAT на выбранный интерфейс. При остановке всё возвращается как было.

> [!NOTE]
> NAT добавляется, только если выбранный фаервол это поддерживает. Без NAT другие устройства смогут выйти в интернет, только если NAT уже настроен отдельно.

На телефоне укажите шлюз — IP-адрес компьютера, а в главном меню выберите интерфейс **в интернет**.

## 📋 Логирование

При каждом запуске `nfqws` программа создаёт файл с журналом:

```text
<cache_dir>/logs/zapret.log
```

В журнале есть всё, что нужно для поиска проблемы:

- **System Info** — система, ядро, дистрибутив, загруженные модули netfilter, версия `nfqws`, сколько стратегий и какая у них версия, сетевые интерфейсы.
- **Config** — настройки пользователя из `conf.env`.
- **Terminal** — сообщения при запуске и вывод самого `nfqws` (загрузка списков, привязка очереди и так далее).
- **Strategy params** — итоговые параметры запуска `nfqws`: путь к программе, все аргументы после подстановки путей, портов и TTL, а также диапазоны TCP/UDP.
- **Stop** — что произошло при остановке `nfqws` (очистка правил, остановка процессов).

При каждом новом запуске журнал начинается заново. Раздел остановки дописывается в конец, когда программа завершает работу.
